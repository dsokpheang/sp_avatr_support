Service tools for the head unit.

A technician utility for authorized servicing of the Avatr and Deepal cockpit (Huawei HarmonyOS head unit): enable debug access over the vehicle's diagnostic link, deploy and verify approved service software, and switch the unit back when the visit is done. On iPad, Mac, Windows and Android.

What it does

Unlock

Connects to the vehicle's diagnostic gateway over the OBD Ethernet link and enables Android Debug Bridge (ADB) access on the head unit for the service session.

Start service

Over the head unit's USB port, deploys and verifies the approved service software and its supporting components, then confirms they are running.

Restore USB

Switches the head unit's USB port back to its normal role, leaving the vehicle as the owner expects it.

On the iPad

The iPad edition is for technicians who carry a tablet rather than a laptop. Unlock and Restore USB run over a USB‑C Ethernet adapter on the OBD cable — the same diagnostic protocol the Mac, Windows and Android editions use.

Start service talks to the head unit's debug (ADB) USB interface. On an M‑series iPad this uses a USBDriverKit driver that matches only that interface and relays its bulk data to the app; the app itself speaks the ADB protocol. The driver touches nothing else on the bus.

The USB interface it drives

Device
Avatr / Deepal head unit (HarmonyOS cockpit)
USB vendor ID
0x12D1
USB product ID
0x107E
Debug interface
class 0xFF · subclass 0x42 · protocol 0x01
Endpoints
one bulk IN / bulk OUT pair

Who it's for

An in-house tool used by our technicians and by owners servicing their own vehicles, with the owner's authorization. It is not for changing a vehicle you are not entitled to service.
